	## Design Tokens

    Colors are applied through **semantic tokens**: names that describe what a color is for (`text`, `textSecondary`, `bgSurface`, `border`, `iconError`) rather than which shade it is. Each theme maps every token to a concrete value, so code written against tokens works in both light and dark mode without changes. Switch the theme in the toolbar to see the components follow.

    Tokens are defined by the `ColorTheme` type in `src/conf/theme/colorThemes/types.ts`, with values in `light.ts` and `dark.ts` next to it.

    ### Using tokens

    In styled-components, read tokens from the theme; no import is needed:

    ```tsx
    const Panel = styled.div`
        background: ${(props) => props.theme.colors.bgSurface};
        color: ${(props) => props.theme.colors.text};
        border: 1px solid ${(props) => props.theme.colors.border};
    `;
    ```

    In a component body, use the `useTheme` hook:

    ```tsx
    import { useTheme } from 'styled-components';

    const theme = useTheme();
    <Icon icon={Warning} color={theme.colors.iconWarning} />;
    ```

    Don't hardcode hex values or import the raw palette (`colors.gray[500]`) for styling: those don't change with the theme. The palette on the [Style Guide](/?path=/docs/style-guide--docs) page is what the tokens are built from, not something to style with directly.
