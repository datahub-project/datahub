	## Icons

    We use the [Phosphor](https://phosphoricons.com) icon library, rendered through our own `<Icon />` component so size, color, rotation, and tooltips work the same way everywhere.

    <a href="/?path=/docs/media-icon--docs">
    	View the component documentation to learn more
    </a>

    Pass the icon component itself to the `icon` prop. Import each icon from its own CSR path so only the icons you use end up in the bundle; importing from `@phosphor-icons/react` directly is blocked by ESLint.

    ```tsx
    import { Icon } from '@components';
    import { ChartLine } from '@phosphor-icons/react/dist/csr/ChartLine';

    <Icon icon={ChartLine} size="lg" weight="bold" />
    ```

    <br />
