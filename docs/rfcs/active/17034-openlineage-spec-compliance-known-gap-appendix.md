## What the PR authors can act on now

The [core/semantic audit](17034-openlineage-evidence/openlineage-153-core-semantic-target-audit-2026-10-01.md) and [facet audit](17034-openlineage-evidence/openlineage-153-facet-target-audit-2026-10-01.md) give the broader 1.53 gaps. The clearest **newly reachable but incomplete** paths are #18175 job tags/owners without producer-scoped replacement, #19734 dataset tags/owners and selected metrics/lifecycle/storage without complete state semantics, and #19736 DatasetEvent acceptance without lifecycle operation, column lineage, or explicit lineage projection. The clearest **inherited** issues are partial RunEvent I/O loss, optional-metadata identity drift, dataset host collisions, missing explicit LineageFacet, and wrong parent-job identity. The short [six-gap dossiers](17034-openlineage-evidence/openlineage-153-spec-gaps-pr-stack-2026-09-29.md) include schema-valid multi-event reproductions and expected/predicted results. #19740/#19800 need persisted and read-API evidence beyond async acceptance and converter goldens. Do not present these source predictions as observed PR-head failures.

The two smoke failures are test-policy mismatches for B13/B14 under the current branch mapping. The local live probes verify their later replacement/authority sequences, but the existing smoke file still has the earlier expectations. No product code, repository tests, PR comments or tickets were changed for this audit.
