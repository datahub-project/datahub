# docs-website Bugbot rules

If `sidebars.js` is edited, then:

- When a hand-authored doc under `docs/` that needs an **explicit** sidebar
  entry was added in the same PR, flag a missing entry (Medium). Skip dirs that
  use sidebar `autogenerated` (e.g. `docs/actions/{actions,events,sources,guides}`)
  and WIP/excluded trees (`docs/wip/`, `docs/what/` stubs).
- When a DataHub Cloud release note under `docs/managed-datahub/release-notes/`
  is added, it must be the **first** entry under "DataHub Cloud Release History"
  (newer releases go at the top).
